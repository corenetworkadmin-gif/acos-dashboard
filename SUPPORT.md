# Support

For installation and reproducible bugs, open an issue in
[the ACOS repository](https://github.com/corenetworkadmin-gif/acos-dashboard/issues).
Include the ACOS revision, OS/architecture, Node version, reproduction steps and redacted error text.
Never attach administrator keys, storage keys, MFA files, private signing keys, companion databases or private backups.

For security issues, use GitHub private vulnerability reporting if enabled. If it is unavailable,
ask the repository owner for a private reporting route without posting exploit details or secrets publicly.
No support response-time guarantee or independent security certification is offered.
